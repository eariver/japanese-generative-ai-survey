# GitHub Copilot automations triggered by comments

- Retrieved at (UTC): 2026-08-30T10:16:12Z

## Source-local observations

- GitHub says Copilot cloud-agent automations can be configured to run when an issue comment or pull request comment is created.
- The source gives examples including generating or updating documentation from a pull-request comment, investigating issue errors, and creating follow-up tasks.
- A trigger is configured by specifying the comment text; GitHub directs users to the repository Agents tab and Automations sidebar.
- GitHub says the feature is available to existing Copilot Pro, Pro+, Max, Business, and Enterprise users.

## Attribution and limitations

- GitHub states that Copilot Business and Copilot Enterprise users need the Copilot cloud-agent policy enabled by an administrator.
- This capture covers the August 3 comment-triggered automation update only; it does not aggregate older cloud-agent functionality into a single launch claim.
