## Source-local observations

- GitHub says that when a task is delegated to Copilot cloud agent, users can set the reasoning level for models that support it.
- GitHub describes the control as changing how much the model reasons before responding; a higher level may improve complex-problem answers but consumes more tokens and credits.
- The reasoning level is selected alongside the model when a task starts, and the cloud agent uses it for that run.
- GitHub says this is available on paid Copilot plans that include cloud agent: Pro, Pro+, Business, Enterprise, and Max.

## Attribution and limitations

- Availability, supported plans, and token/credit implications are GitHub's changelog claims.
- The page does not establish that this was a new model launch or that older June/July cloud-agent features were part of this update; this capture is limited to the August 3 reasoning-level change.
