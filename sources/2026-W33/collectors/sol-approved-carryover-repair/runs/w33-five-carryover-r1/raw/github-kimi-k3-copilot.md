# Kimi K3 in GitHub Copilot

- Source URL: https://github.blog/changelog/2026-08-06-kimi-k3-is-now-available-in-github-copilot/

- Retrieved at (UTC): 2026-08-30T10:16:12Z
- Explicit publication/update date stated by the source: 2026-08-06.

## Source-local observations

- GitHub states that Kimi K3, described there as an open-weight model, is now generally available in GitHub Copilot and is hosted by GitHub on Fireworks AI.
- The editor notes record a temporary rollout pause while GitHub mitigated an incident with GitHub Actions and a resumed rollout on August 6, 2026. The resumed note says billing uses provider list pricing under usage-based billing.
- GitHub says rollout begins for Copilot Pro, Pro+, Max, Business, and Enterprise plans, with model-picker availability across Visual Studio Code, Visual Studio, Copilot CLI, Copilot cloud agent, the Copilot app, github.com, GitHub Mobile, JetBrains, Xcode, and Eclipse.
- GitHub says rollout is gradual and that Copilot Business and Enterprise keep Kimi K3 off by default until a plan administrator enables the Kimi K3 policy.
