How it was built

Post-trained by fal Research, with Black Forest Labs

FLUX 3 Max starts from Black Forest Labs' FLUX 3. fal Research worked on three layers at once, because a gain at one layer opens room at the next, and is continuing to post-train the model.

Post-training

Working with Black Forest Labs, fal Research kept training FLUX 3 to improve visual fidelity, motion coherence, prompt adherence and image-to-video quality, without trading one off against another.

Inference optimization

The team changed how the model executes to cut generation latency and raise throughput without giving up quality, bringing a 10-second video down to 12.45 seconds from 126.44 for FLUX 3.

Systems engineering

The serving path around the model was tuned on fal's own inference engine, so the speedup holds up in reliable, scalable production workloads.

API Documentation

Build with the FLUX 3 Max API

The client API handles the request submit protocol. It will handle the request status updates and return the result when the request is completed.

import { fal } from "@fal-ai/client";

const result = await fal.subscribe("blackforestlabs/flux-3-max/text-to-video", {
  input: {
    prompt:
      "A single-file line of longhorns swims a cold jade river at dawn, only heads and wide pale horns above the water, riders on the far bank. Wide, still, enormous.",
  },
  logs: true,
});

FAQ

Common questions about FLUX 3 Max

What is FLUX 3 Max?

FLUX 3 Max is a post-trained video model from fal Research, built in partnership with Black Forest Labs on FLUX 3. It is tied for #1 in image-to-video quality on Artificial Analysis's preliminary arena and generates a 10-second video in about 12 seconds, at 720p. fal Research is continuing to post-train it.

What is a post-trained model?

A post-trained model starts from an existing base model and keeps training it on new data and objectives, rather than training from scratch. The base model supplies its general knowledge of motion, light and composition; post-training sharpens specific behaviors on top of it, such as following prompts more closely or producing more polished video. fal Research pairs post-training with inference optimization and systems engineering, so a model can get better and faster at the same time.

Who made FLUX 3 Max?

fal Research made FLUX 3 Max in collaboration with Black Forest Labs, who built the base model, FLUX 3. Black Forest Labs brought the foundation model; fal Research brought post-training, inference optimization and systems engineering. It comes from the same team that built H3 Max.

How much does FLUX 3 Max cost?

FLUX 3 Max is 75% off until November 7, so it runs at $0.0425 per second at 720p. List price is $0.17 per second at 720p. Billing is per second of output video, with no minimums and no subscription. Current pricing is listed on the fal.ai pricing page.

Which FLUX 3 Max endpoints are available?

Two at launch: text to video and image to video. Information updated as of October 18, 2026.

How is FLUX 3 Max different from FLUX 3?

FLUX 3 is Black Forest Labs' own release, with draft, keyframe and extend endpoints. FLUX 3 Max is the post-trained version, focused on text to video and image to video. In Artificial Analysis's preliminary image-to-video arena it scores 50 Elo points higher than FLUX 3 (1,139 against 1,089), and it generates a 10-second video about 10 times faster (12.45 seconds against 126.44).

How fast is FLUX 3 Max?

FLUX 3 Max generates a 10-second video in 12.45 seconds, against 277.80 seconds for Seedance 2.5: about 22 times faster at the same 1,139 Elo in Artificial Analysis's preliminary image-to-video arena. The only faster model in that comparison is H3 Max, fal Research's other post-trained model, at 7.55 seconds.
