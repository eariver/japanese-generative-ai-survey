== VM-D003 [PRIMARY] PAPER/VERIFIED/MATERIAL: ImageNet Classification with Deep CNNs / AlexNet (Krizhevsky, Sutskever, Hinton, 2012)
   rationale: AlexNet large-scale supervised + GPU-scaling break; required D01 anchor.
   CLAIM claim-1 [PRIMARY_SUBJECT]: A large deep CNN (60M parameters, 650K neurons; 5 convolutional + 3 fully-connected layers with 1000-way softmax) trained on 1.2M ImageNet images achieves top-1/top-5 errors of 37.5%/17.0% (LSVRC-2010) and a winning 15.3% top-5 (ILSVRC-2012) vs 26.2% for the runner-up.
   CLAIM claim-2 [PRIMARY_SUBJECT]: Bottleneck addressed: small labeled datasets and prohibitive cost of large high-resolution CNNs; mechanism stack is data scale (ImageNet) + model capacity (depth/breadth-controlled CNN with locality/stationarity priors) + efficient GPU 2D-convolution implementation + non-saturating neurons + dropout against overfitting (5-6 days on two GTX 580 3GB GPUs).
   CLAIM claim-3 [PRIMARY_SUBJECT]: What became possible: large-scale supervised visual representation learning as a reusable substrate; the paper closes by stating results should improve with faster GPUs and bigger datasets — the scaling-recipe reading.
   EVENT event-1: 
   LIMIT limitation-1: Single-dataset (ImageNet) scope; transfer claims require successor sources (ResNet record).
   LIMIT limitation-2: Recipe reading vs architectural-novelty reading must both be carried; the paper's own framing supports the recipe side.
== VM-D004 [PRIMARY] PAPER/VERIFIED/MATERIAL: Deep Residual Learning for Image Recognition / ResNet (He et al., 2015)
   rationale: ResNet residual-optimization break with detection/segmentation transfer; required D01 anchor.
   CLAIM claim-1 [PRIMARY_SUBJECT]: Degradation diagnosis: beyond vanishing/exploding gradients (addressed by init + normalization), deeper plain nets show higher TRAINING error — an optimization (not overfitting) problem; the constructed identity-mapping argument shows deeper models should do no worse.
   CLAIM claim-2 [PRIMARY_SUBJECT]: Mechanism change: residual reformulation F(x)=H(x)-x with parameter-free identity shortcuts (Eq.1; projection Ws only for dimension matching, Eq.2); bottleneck 1x1-3x3-1x1 blocks for economy; 152-layer net at 11.3 GFLOPs still cheaper than VGG-19.
   CLAIM claim-3 [PRIMARY_SUBJECT]: Results: 152-layer single-model 4.49% top-5 val; ensemble 3.57% top-5 test (ILSVRC 2015 1st place); COCO detection +6.0 mAP (28% relative) attributed solely to learned representations; 1st places also in ImageNet detection/localization and COCO segmentation.
   CLAIM claim-4 [PRIMARY_SUBJECT]: What remains missing: 1202-layer CIFAR model trains (<0.1% train error) but tests worse (overfitting without maxout/dropout) — depth scaling has a regularization boundary the paper leaves open.
   EVENT event-1: 
   LIMIT limitation-1: Highway-network comparison is concurrent-work framing; later pretraining-recipe readings (DeiT/Swin) qualify architecture-triumphalism.
   LIMIT limitation-2: Detection gains use Faster R-CNN baselines of 2015 vintage.
