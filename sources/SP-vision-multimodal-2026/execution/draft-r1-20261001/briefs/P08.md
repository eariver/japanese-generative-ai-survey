== VM-D058 [PRIMARY] PAPER/VERIFIED/MATERIAL: Flamingo (Alayrac et al., 2022)
   rationale: Flamingo few-shot gated-cross-attention bridge with inherited-LM limits.
   CLAIM claim-1 [PRIMARY_SUBJECT]: Bridge pretrained vision-only + language-only models with gated cross-attention dense layers; train on interleaved web corpora; ingest images/video; single model reaches few-shot SOTA across open/close-ended VQA/captioning, beating models fine-tuned on 1000x more task data.
   CLAIM claim-2 [PRIMARY_SUBJECT]: Paper's own limitation: inherits pretrained-LM weaknesses including LM-prior-driven hallucinations — the language-prior exhibit for D10.
   EVENT event-1: 
   LIMIT limitation-1: Closed training-data regime; resampling predecessor role noted for D09, not duplicated.
== VM-D059 [PRIMARY] PAPER/VERIFIED/MATERIAL: BLIP-2 (Li et al., 2023)
   rationale: BLIP-2 frozen-frozen Q-Former bridge; compute-efficiency exhibit.
   CLAIM claim-1 [PRIMARY_SUBJECT]: Two-stage bootstrapping from frozen image encoder (stage 1, Q-Former representation learning) and frozen LLM (stage 2, generative learning); SOTA VL tasks with far fewer trainable parameters (beats Flamingo80B by 8.7% zero-shot VQAv2 at 54x fewer trainable params); emergent instruction-following image-to-text generation.
   EVENT event-1: 
   LIMIT limitation-1: Two-stage cost/complexity; instruction-tuning successors (InstructBLIP/LLaVA) complete the picture.
