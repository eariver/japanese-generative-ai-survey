== VM-D005 [PRIMARY] PAPER/VERIFIED/MATERIAL: R-CNN (Girshick et al., 2014)
   rationale: R-CNN region-proposal origin + pre-train/fine-tune paradigm.
   CLAIM claim-1 [PRIMARY_SUBJECT]: R-CNN applies high-capacity CNNs to bottom-up region proposals and improves VOC 2012 mAP by >30% relative (53.3%) via two insights: CNN-on-proposals for localization, and supervised pre-training (classification) followed by domain-specific fine-tuning when detection labels are scarce.
   CLAIM claim-2 [PRIMARY_SUBJECT]: Bottleneck addressed: VOC detection plateau under complex ensembles of handcrafted features; mechanism fuses classical CV (region proposals) with deep learning rather than opposing them.
   CLAIM claim-3 [PRIMARY_SUBJECT]: Historical role (VM-O02): region-proposal detection origin; pre-training/fine-tuning paradigm later inherited across vision.
   EVENT event-1: 
   LIMIT limitation-1: Multi-stage pipeline speed addressed only as future work; R-CNN itself is slow by later standards.
   LIMIT limitation-2: Failure-mode analysis uses Hoiem et al. tooling of its era.
== VM-D006 [PRIMARY] PAPER/VERIFIED/MATERIAL: Faster R-CNN (Ren et al., 2015)
   rationale: Faster R-CNN two-stage capstone; anchor/NMS machinery reference.
   CLAIM claim-1 [PRIMARY_SUBJECT]: Region Proposal Network shares full-image convolutional features with the detector, making proposals nearly cost-free; unified system runs 5fps on VGG-16 with state-of-the-art VOC 2007/2012 and COCO accuracy at 300 proposals/image; ILSVRC/COCO 2015 1st-place foundations.
   CLAIM claim-2 [PRIMARY_SUBJECT]: Interface contract: fully-convolutional RPN predicts object bounds + objectness per position (the 'where to look' attention framing); this anchor/NMS machinery becomes the fossilized assumption DETR later removes.
   EVENT event-1: 
   LIMIT limitation-1: Anchor design and NMS remain hand-designed; small-object/edge behaviors need successor sources.
== VM-D007 [PRIMARY] PAPER/VERIFIED/MATERIAL: YOLO (Redmon et al., 2016)
   rationale: YOLO one-stage operating-point origin; latency/accuracy trade-off reference.
   CLAIM claim-1 [PRIMARY_SUBJECT]: Detection reframed as regression to spatially separated boxes + class probabilities in one evaluation: base model 45 FPS real-time, Fast YOLO 155 FPS at 2x mAP of other real-time detectors; fewer background false positives than R-CNN-family, more localization errors.
   CLAIM claim-2 [PRIMARY_SUBJECT]: Stated limitations (paper's own): grid-cell spatial constraints (2 boxes/1 class per cell) cap nearby-object counts; small grouped objects (flocks), unusual aspect ratios, coarse features, and small-box IOU sensitivity; main error source is localization.
   CLAIM claim-3 [PRIMARY_SUBJECT]: Generalization claim: YOLO representations transfer natural-images-to-artwork better than DPM/R-CNN — the operating-point generality exhibit.
   EVENT event-1: 
   LIMIT limitation-1: Accuracy lags state-of-the-art systems of its generation by the paper's own account; later YOLO versions are distinct products.
== VM-D010 [PRIMARY] PAPER/VERIFIED/MATERIAL: DETR (Carion et al., 2020)
   rationale: DETR set-prediction transition removing anchors/NMS; base of grounding detectors.
   CLAIM claim-1 [PRIMARY_SUBJECT]: Detection as direct set prediction: bipartite Hungarian matching loss (class NLL + L1 + scale-invariant GIoU box loss) plus Transformer encoder-decoder with learned object queries and parallel decoding; no anchors, no NMS, no specialized libraries.
   CLAIM claim-2 [PRIMARY_SUBJECT]: Results: COCO-val parity with heavily-tuned Faster R-CNN at equal parameters (42 AP R50, 44.9 DC5-R101); large-object dominance APL +7.8 attributed to global self-attention; small-object deficit APS -5.5; panoptic extension competitive (46 PQ test) especially on stuff classes.
   CLAIM claim-3 [PRIMARY_SUBJECT]: Costs stated by the paper: 300-500-epoch AdamW schedules (3 days on 16 V100), auxiliary decoding losses required, object-query slot specialization, NMS provably unnecessary only from later decoder layers (self-attention duplicate inhibition).
   EVENT event-1: 
   LIMIT limitation-1: Small-object deficit and training cost are paper-stated open challenges; FPN-style successors address them outside this source.
== VM-D011 [PRIMARY] PAPER/VERIFIED/MATERIAL: DINO detector (Zhang et al., 2022)
   rationale: DINO detector: DETR capstone and Grounding DINO substrate (name-disambiguated).
   CLAIM claim-1 [PRIMARY_SUBJECT]: DETR-lineage capstone with improved denoising anchor boxes: 49.4 AP in 12 epochs / 51.3 in 24 epochs (R50, COCO), +6.0/+2.7 AP over DN-DETR; Objects365-pretrained SwinL reaches 63.2/63.3 AP val/test-dev with reduced model/data scale vs leaderboard peers.
   CLAIM claim-2 [PRIMARY_SUBJECT]: Role (VM-O02/VM-O08): technical base of Grounding DINO; must always be qualified as 'DINO detector' vs DINO self-supervised (CV2-DM-006 rule).
   EVENT event-1: 
   LIMIT limitation-1: Leaderboard-comparison scope; grounding behavior requires Grounding-DINO-side sources.
== VM-D012 [PRIMARY] PAPER/VERIFIED/MATERIAL: YOLO-World (Cheng et al., 2024)
   rationale: YOLO-World: open-vocabulary detection at a real-time operating point; D02-D07B bridge.
   CLAIM claim-1 [PRIMARY_SUBJECT]: RepVL-PAN (re-parameterizable vision-language aggregation) + region-text contrastive loss bring open-vocabulary detection into the YOLO operating point; LVIS 35.4 AP at 52 FPS (V100) zero-shot; fine-tuned variants extend to detection and open-vocabulary instance segmentation.
   CLAIM claim-2 [PRIMARY_SUBJECT]: Stated trade-off: fine-tuning on O365/LVIS-style closed vocabularies can degrade zero-shot generalization (CLIP generalization eroded by 365-category fine-tuning); pre-training with fine-annotated + pseudo-annotated data combination performs better — an X01 data-contract finding.
   EVENT event-1: 
   LIMIT limitation-1: YOLO product-line confusion risk; version-bound claims only; edge-deployment burden noted as motivation, not established result.
== VM-D008 [SUPPORTING] PAPER/VERIFIED/CONTEXT: SSD (Liu et al., 2016)
   rationale: SSD non-YOLO one-stage branch; thin lineage-completeness node.
   CLAIM claim-1 [PRIMARY_SUBJECT]: Single-shot multi-box detector discretizing box space into default boxes over scales/aspect ratios across multi-resolution feature maps; SSD300 74.3-77.2% mAP VOC2007 at 59 FPS Titan X, SSD512 76.9-79.8% outperforming Faster R-CNN at 3x speed.
   EVENT event-1: 
   LIMIT limitation-1: Default-box tiling vs receptive-field alignment left as future work by the paper itself; thin treatment per lineage-completeness role.
== VM-D009 [SUPPORTING] PAPER/VERIFIED/CONTEXT: RetinaNet / Focal Loss (Lin et al., 2017)

   CLAIM claim-1 [PRIMARY_SUBJECT]: Diagnosis: extreme foreground-background imbalance is the central cause of one-stage accuracy lag; focal loss (1-pt)^gamma down-weights easy negatives; RetinaNet matches one-stage speed while surpassing two-stage accuracy.
   EVENT event-1: 
   LIMIT limitation-1: Loss-centric contribution; architecture claims require detector-side sources; thin treatment per role.
