\section{MemTrapBenchがLLMメモリ機構を再評価}
新しいベンチマークMemTrapBenchが、代表的なLLM memory framework 5種を比較し、すべてが「memoryなし」のbaselineを下回ったとする結果が共有された。取得されたmemoryが正確で関連性を持つ場合でも性能低下が生じたとされ、agentやlong-context systemで「memoryを追加すれば改善する」という前提に疑問を投げかける結果として注目された。
