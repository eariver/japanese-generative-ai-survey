\section{Grok Build CLI v1.0.11}
Grok Build CLIのv1.0.11では、ヘッドレス環境のセッション再開選択、既定の権限モード設定、ターン時間表示、auto-allow改善などが報告された。バックグラウンド待機や権限プロンプト、貼り付け、画像プレビューなどの不具合修正も含まれる。Grok入力ではコミュニティ追跡投稿を主要根拠としており、公式xAIドキュメントでの確認は今後の課題とされている。
