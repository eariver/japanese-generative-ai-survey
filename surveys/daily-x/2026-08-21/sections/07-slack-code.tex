\section{「Slack Code」を巡る報道}
複数の投稿で、Slackが「Slack Code」を発表し、Claude、Devin、CodexなどのAIエージェントをチャンネル内で呼び出してコード生成・レビュー・プレビューを協働させる機能を提供すると報じられた。GitHubやVercelとの統合、会話コンテキストの保持も特徴として挙げられている。一方、今回のGrok収集では一次のSlack公式投稿を確認できていないため、現時点では報道・まとめ投稿を通じて共有された情報として扱う。
