\section{Agent Coding Plane}
\sectionkicker{AGENT PLANE}
\begin{wideflow}
{\Large\bfseries 道具の面が組み替わる}\par
\smallskip
{\color{SurveyMuted}続きの持ち運び、置き場の取り込み、会話の文脈化、審査と見張りが一週で並び、便利さと預け先の問いが同時に前に出た。}\par
\end{wideflow}

8月26日のVS Code 1.135では、Agent Host Protocolという仕様の草案が切り離しの要として報じられる\cite{vscodeahp}。会話の続きをJSON-RPCやWebSocketで運び、Copilotの命令道具や応用、他社の符号道具を行き来させる構想で、利用条件の細部は一次資料での確認を待つ。仕様は1.0前の草案で配線の型も安定せず、本番の継続的結合に載せる段階ではない。第三者の測定とされる数値は測定値として本文に取り込まず、提供側や報道の説明として区別する。

8月25日に報じられたCursor Originは、編集画面の中にgit置き場を持ち、ProやTeams、Enterprise向けの早期試用として置き場や pull request の閲覧、GitHubからの同期を束ねる内容である\cite{cursororigin}。GitHubを正本とする写しや積み重ねた pull request、道具を意識した結合待ちの説明は提供側の説明として受け止め、文書での確認を待つ。試用の時期が数時間のGitHub障害と重なったことは時刻の一致として報じられるが、因果の主張はしない。学習利用や保持の方針文は確認できておらず、欠落は推測で埋めず未解決として残す。

GitHub Copilotの符号道具がTeamsの会話を仕事の文脈として使えるという試し提供は、8月25日の報道で伝えられる\cite{copilotteams}。机上と網上の両面からの言及で仕事を調べ、実装し、pull request を開く流れとされ、置き場の権限や pull request の統制は保たれるという説明である。提供条件や対応範囲の細部は一次文書での確認を待ち、影のAI削減といった見立ては編集部の解釈であり資料の主張ではない。

\begin{claimboundary}[未解決の境界]
三件の facts はいずれも報道経由であり、一次文書での確認を待つ。障害時刻の一致を原因として読まず、方針の欠落を推測で補わない。第三者の測定値を本文の測定として扱わない。
\end{claimboundary}

土台側では8月27日にHarnessが道具対応の置き場と符号審査を示し、数千の同時 pull request や投入に耐える規模やMCPと命令道具の両面、50GBの無償枠からの移行手段が企業発表として示される\cite{harness}。規模や審査の質の主張は独立の評価を欠き、無償枠を超える価格や地域、導入事例は今回の資料では確かめられない。一方、8月25日に出たgrithはLinux向けのOS層の代理として、ptraceとseccomp-BPFによる18の決定的な選別を道具の経路の外に置かず、大規模模型を経路に入れない設計が一次資料で確かめられる\cite{grith}。0.02msの中央値や752回の環境読み取りといった動機づけの数値は提供側の報告であり、仕組みの説明を超える効果の断定はしない。Linuxのみという範囲も明示する。
