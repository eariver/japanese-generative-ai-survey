9月2日のMicrosoft発表（8月更新の構え）で、Copilot StudioのGitHub Copilotハーネスが一般提供となった\cite{copilotharness}。モデルとエージェント・ワークフローの間に立ち、モデル呼び出しや文脈、ツール、MCPサーバー、接続エージェントを再帰的な適応計画で束ね、重い推論を行うエージェントとワークフローの土台と位置づけられる。スキルと記憶を支え、Word、Excel、PowerPoint、PDFをネイティブに作り直し、各タスクをCopilot Studioの安全なサンドボックスで走らせ、標準ハーネスと共存する。請求書を読み、注文書を突き合わせ、不足情報を集め、例外を回す買掛エージェントの例示も一次資料で確認できる。同じ更新で、エージェント向けワークフローとMCPサーバー（一般提供）、エージェント向けWindows 365 MCPサーバー（一般提供）が示され、接続エージェントやWork IQの組織文脈、記憶、直接のファイル解析、環境単位のエージェントテレメトリはプレビュー提供、Entra Agent IDの自動プロビジョニングは2026年7月以降の新規エージェントに適用、Claude Sonnet 5とGPT-5.5 Chatは主要モデルとして一般提供、リアルタイムエージェントはプレビューとされる。一般提供とプレビューの表示は取り違えない。提供側blogのみであり、推論の質やツール使いの信頼性、サンドボックスの保証の独立検証はない。プレビューの隣接機能は振る舞いと公開が変わり得る。モデルの公開は価格や地域や上限の細部を欠く。

\begin{claimboundary}[提供とプレビューの境界]
一般提供とプレビューを取り違えない。推論の質やサンドボックスの保証の独立検証はない。価格や地域の細部は欠落のまま残す。
\end{claimboundary}

9月1日にKiloが示したJetBrains向けは、JetBrainsの分割表示に向けたKotlinネイティブのプラグインとして、JetBrainsを離れず並列のコーディングエージェントを回す管理室の位置づけである\cite{kilojetbrains}。各タスクは分離されたgit worktree（ブランチ、作業ディレクトリ、未コミット差分、セッション履歴ごと）に載り、ベースブランチや既存ブランチ、貼り付けたGitHub pull requestのURLから作れ、Agent Managerで束ね、探索的セッションを引き継ぐWorktreeで続ける操作が添えられる。既存のRun設定をworktreeに適応させ、実行中のプロセスやBuild・RebuildをAgent Managerに示し、フレームを使い回すワンクリックの全フレームデバッグ、関連pull requestの番号・題名・状態とベース比較、未コミット差分とブランチ差分の分離やファイル・行数が示される。600超の切替え可能なモデル（クレジットか持込鍵、エージェントごとのモデル固定、頻繁で低コストな処理向けの小型モデル、データ利用バッジと組織単位のプロバイダー・モデル統制）は、CLIとVS CodeとJetBrainsとクラウドを跨ぐ共通のオープンソースKilo CLIランタイムとkilo.jsoncの上で動くとされる。提供側blogのみであり、並列の隔離やRun適応、遠隔開発の振る舞いの独立試験はない。600超の数やバッジの対象範囲は時点の提供側言明である。Product Hunt初日の反応や価格・クレジット費用はこの資料では確かめられない。
