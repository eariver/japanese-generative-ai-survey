\section{Agent Harness Plane}
\sectionkicker{AGENT HARNESS}
\begin{wideflow}
{\Large\bfseries 道具の土台が前に出る}\par
\smallskip
{\color{SurveyMuted}企業と開発者の道具土台を、一般提供と試しの区別ごと示す。}\par
\end{wideflow}

9月2日のMicrosoft発表（8月更新の構え）で、Copilot StudioのGitHub Copilot harnessが一般提供となった\cite{copilotharness}。模型と道具・仕事の間に立ち、模型呼びや文脈、道具、MCP仕掛け、接続道具を再帰の適応計画で束ね、重い推論の道具と仕事の土台と位置づけられる。技能と記憶を支え、Word、Excel、PowerPoint、PDFを生来作り直し、各仕事をCopilot Studioの安全な砂場で走らせ、標準harnessと共存する。請求書を読み、注文書を突き合わせ、欠けを集め、例外を回す買掛道具の例示も一次資料で確認できる。同じ更新で、道具としての仕事流しとMCP仕掛け（一般提供）、道具向けWindows 365 MCP仕掛け（一般提供）が示され、接続道具やWork IQの組織文脈、記憶、直の文書解析、道具単位の遠隔測定は試し提供、Entra Agent IDの自動備えは2026年7月以降の新規道具に適用、Claude Sonnet 5とGPT-5.5 Chatは主要模型として一般提供、実時間道具は試しとされる。一般提供と試しのlabelsは取り違えない。提供側blogのみであり、推論の質や道具使いの信憑性、砂場の保証の独立検証はない。試しの隣接機能は振る舞いと公開が変わり得る。模型の公開は価格や地域や上限の細部を欠く。

\begin{claimboundary}[提供と試しの境界]
一般提供と試しを取り違えない。推論の質や砂場の保証の独立検証はない。価格や地域の細部は欠落のまま残す。
\end{claimboundary}

9月1日にKiloが示したJetBrains向けは、JetBrainsの分割方式に生来のKotlin差し込みとして、JetBrainsを離れず並列の符号道具を回す統制室の位置づけである\cite{kilojetbrains}。各仕事は孤立したgit worktree（枝、仕事場、未投入差分、対話記録ごと）に載り、基底枝や既存枝、貼ったGitHub pull request URLから作れ、Agent Managerで束ね、試し対話をWorktreeで続ける操作が添えられる。既存のRun設定をworktreeに適応させ、走行中やBuild・RebuildをAgent Managerに出し、枠を使い回す一押しの全枠debug、結びpull requestの番号・題・状態と基底比較、未投入と枝差分の分離や文件・行数が示される。600超の切替え模型（creditか持込鍵、道具ごとの固定、小さな模型の頻用割、資料利用章と組織の提供・模型統制）は、CLIとVS CodeとJetBrainsと雲を跨ぐ共有の開かれたKilo CLI駆動とkilo.jsoncの上で動くとされる。提供側blogのみであり、並列の隔離やRun適応、遠隔開発の振る舞いの独立試験はない。600超の数や章の被覆は時点の提供側言明である。Product Hunt初日の受けや価格・credit費用はこの資料では確かめられない。

\begin{technicalnote}[時点の言明]
模型数や章の被覆は時点の提供側言明であり、価格や初日の受けはこの資料では確かめられない\cite{kilojetbrains}。
\end{technicalnote}
