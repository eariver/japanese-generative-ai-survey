9月にAnthropicが示したClaude Fable 5.1とClaude Mythos 5.1は、同じ模型を守りの段違いで出す位置づけである\cite{fablemythos}。Fable 5.1は一般提供、Mythos 5.1はcyberと生命の仕事向けの信頼接続programs経由とされる。Fable 5.1の価格は、cache読みが100万tokenあたり0.25ドル（75\%減）、通常のtoken課金仕事で約25\%安く、道具性の高い仕事で最大約45\%安いとされ、それ以外は入力10ドル、出力50ドル、API名claude-fable-5-1である。測定値の差分としてTerminal-Bench-Science 52.6\%、Terminal-Bench 4.0 55.8\%（Mythosは60.9\%）、GDPval-AA v2 1853、OSWorld 2.0部分77.9\%・厳密41.7\%、AutomationBench 31.4\%、CursorBench 73.4\%が掲げられる。守りは、Mythosの化学・生物の能力がMythos 5を上回り次のRSP危険段には届かず、最も強いAnthropicのcyber能力でありながら下位のFCF危険区分で重大な脱獄は見つからず、生物の守りは良性問いへの発火が85\%減、cyberの守りは平均約6割の介入減とされる。いずれも研究室の報告であり、外部の再現はない。Mythosの審査基準や透かし検出APIの試し範囲は発表されたprogramsであり、動いた配備の観察ではない。科学の逸話は提供側が選んだ事例報告であり、統制された証拠ではない。

測定値と守りの数値は研究室の報告であり、外部の再現を待つ。審査基準や透かしは発表されたprogramsであり、配備の観察ではない。

9月2日にGoogleが出したGemini 3.8 FlashとGemini 3.8 Flash Cyberは、同じ基礎知能を二様で出す位置づけである\cite{gemini38flash}。Flashは汎用の働き馬、Flash CyberはFairwind Program経由で信頼された守り手向けとされる。Flashの導入価格は2026年12月31日まで入力0.75ドル、出力3.75ドル（100万tokenあたり）、2027年1月1日から入力1.50ドル、出力7.50ドルである。能力主張は、長い符号や道具の伸び、Vals Finance Agent V2やHarvey Legalでの3.7 Flashや他旗艦超え、HLE-Verified 54.9\%、高い努力段での余分の推論と道具呼びの丁寧さとtoken増しとされる。Flash Cyberは、CyberGymの先端級の発見、内部20言語の脆弱発見で7割超、CWE-Bench pass@1 47.2\%対先端47.8\%（低費用）、Chromeの2.6倍の正patch、Wizの想起7.5から9.7\%増（2.3から5.2倍の低費用）、2時間内のGoogleの重大1件とされる。測定値やpatch想起や発見の数値は手法の消費なしの提供側報告であり、独立の再現を待つ。内部20言語は非開示であり、CyberGymやCWE-Bench走行はGoogle報告である。WizやChrome班の帰属はGoogle経由の伝聞であり、独立に確かめていない。DeepMindの模型札の細目はHOLDの文脈資料に留め、ここでは別候補として持ち上げない。

9月2日にMetaが出したMuse Spark 1.3は、Muse CodeとMeta Model API（dev.meta.ai）上で最大推論つきで使えるとされる\cite{musespark}。提供側の符号・道具の伸びとして、確かめ問いと重大動作の確認を伴う長い協働、長い指示の保持、単線の多重こなし、能力の自己把握、Muse Spark 1.2比で道具呼び約2割減・token約25\%減の整った符号ぶりが挙げられる。守りの伸びとして、敵対やprompt注入への耐性と、複雑な道具仕事での不可逆動作の調整が挙げられる。いずれも提供側の報告であり、再現はない。頁面に埋まる測定値の絵表の数値は取得markdownから復元できず、連動の多様評価の手法報告も消費していないため、測定値はいっさい本文に取り込まない。開いた重みの公開や大型は道筋の言葉であり、出荷の事実ではない。
